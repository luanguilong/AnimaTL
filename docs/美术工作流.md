# anima 过场编辑器 — 美术工作流(零代码)

> 面向 3D 美术。全程不需要写代码、不需要命令栏。

## 一次性准备(装插件)

1. 浏览器打开 `http://192.168.110.69:34871/anima.rbxm` 下载;
2. 把文件放进 `%LOCALAPPDATA%\Roblox\Plugins\`(覆盖同名旧文件);
3. 重开 Studio,工具栏出现 **Anima ▸ 过场编辑器**。
4. 以后插件有更新,重复 1–2 即可(浏览器若"秒下完"是缓存,按 Ctrl+F5)。

## 日常:做一条过场

1. 点工具栏 **过场编辑器** 打开时间轴;
2. 排戏:
   - **＋ 相机** 摆机位,拖生效段;主视口取景后「采集视口打帧」;
   - **＋轨道** 加 动画 / 特效 / 音效 / 属性(如透明度渐变)/ 事件 轨,右键打帧;
   - **Moon 做的动画**:把 Moon 存档(StringValue)放到场景里 → 📂 菜单底部
     「从 Moon Animator 导入」→ 相机轨和角色动作(🦴)一起进来;
   - 空格 = 播放暂停;Shift+滚轮上下滚轨道;滚轮缩放时间轴;
3. **💾 导出**,起个名字(如 `my_cutscene`)。

## 让它在游戏里按键播放(共 3 步,都在 📂 菜单里)

1. 📂 → **⌨ 绑定播放按键…** → 选你的过场 → 输入按键(如 `1`、`V`);
2. 📂 → **🚀 部署运行时到本游戏**(每次插件更新后点一次即可);
3. **F5 → 按你绑的键**,过场就播了(相机、动作、特效、音效全套)。

## 常见问题

| 现象 | 处理 |
|------|------|
| F5 按键没反应 | 先点一次 📂 → 🚀 部署;确认 ⌨ 绑定过按键 |
| Moon 导入后相机离人很远 | Moon 工程里要给人物 rig 在第 0 帧 K 一个位置键,重新保存再导 |
| 角色不做动作 | 角色必须是 **R6**(问技术把场景设成 R6 出生) |
| 特效在小窗里看不见/简陋 | 小窗是近似预览;真效果 F5 看 |
| 时间轴上动画块宽度不对 | 等几秒会自动校正(动画资源在加载) |

## 需要找技术的情况

- 要把过场用到**另一个游戏 place**:让技术复制
  `ReplicatedStorage.Anima.Cutscenes.<过场名>` 过去,再在那边点一次 🚀;
- 过场要接游戏逻辑(开门、给道具):告诉技术你打的**事件名和 payload**。
